## 1. 项目是什么

Pek 生态 Redis 客户端的 **Zig** 实现，语义与字节格式对齐：

- C# `DH.NRedis`（`G:\Code\Pek.FrameWork\DH.NRedis`）
- Rust `Pek.RRedis`（`G:\Code\Rust\Pek.RRedis`）

三方连接**同一个 Redis 实例**、使用**同一套键与编码**，业务可逐用例迁移。

## 4. 关键设计（改动前必读）

1. **按值语义**：`Client` 按值保存 `ConnConfig`，`resp.Reader` 按值保存 `Stream`。
   不要再把 `&self.xxx` 存进会被按值返回的结构体（会悬空，Windows 上表现为 `INVALID_HANDLE`）。
2. **超时**：Windows Threaded 后端不支持连接超时与 `operateTimeout`；读写超时走
   `SO_RCVTIMEO`/`SO_SNDTIMEO`（`client.setSocketTimeouts`）。阻塞命令临时放宽后再恢复。
3. **数组所有权**：`Redis.expectArray` 返回借用切片，元素由返回值 `Value.deinit` 释放；
   调用方只复制需要的数据，**不要**再 `free(array)`。
4. **错误**：库统一错误集 + `lastError()`（连接/服务端/协议/池），文案包含「做什么 + 为什么 + 上下文」。
5. **前缀**：只在 `FullRedis` 层补；`Redis`/结构体层拿到的都是完整键。
6. **锁**：值格式、TTL、抢占与释放必须与 C#/Rust 一致；时钟用 `bootTicksMs()`，不要用 wall clock。

## 5. 验证口径

- 单测覆盖协议/配置/编码/锁值解析；
- 集成测试用回环假 Redis（`tests/support/mock_redis.zig`）覆盖：握手、RESP3、批量、管道、前缀/搜索、锁、结构体、PubSub、连接池并发；
- 改动即跑 `tools/regression.ps1`，汇报贴实际输出（测试数、退出码）。
