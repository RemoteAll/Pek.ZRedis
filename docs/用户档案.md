## 决策记录（含用户原话）

- **2026-11-18（首轮）· 对齐范围与分层**
  - 参考实现：C# `DH.NRedis`、Rust `Pek.RRedis`；Zig 侧命名 `Pek.ZRedis`（库 `pek_zredis`）。
  - 公共基础件复用 `zzig`（`compat` 时钟/睡眠、`DateTime`），不重复造轮子。
  - 分阶段交付：本轮完成协议/连接/池/编码/基础命令/FullRedis/结构体/PubSub；
    队列、Stream、服务层、Tair、拓扑、TLS 列入下一里程碑并在 `docs/移植对照-NRedis.md` 留缺口。
  - TLS **不静默降级**：`Tls=true` / `rediss://` 当前返回 `error.Unsupported` 并写清原因。

- **2026-11-18（首轮）· 实测修正（均有证据）**
  - 句柄悬空：`Client` 按值返回后，`Reader` 保存的 `&stream`、`Client` 保存的 `*ConnConfig` 失效，
    Windows 报 `error.Unexpected NTSTATUS=0xc0000008 (INVALID_HANDLE)`；改为按值持有/快照后消除。
  - 超时：Zig 0.17 Windows Threaded 对 `netConnectIpWindows(timeout)` 是 `@panic`，
    对 `operateTimeout` 返回 `error.ConcurrencyUnavailable`；改为套接字 `SO_RCVTIMEO`/`SO_SNDTIMEO`。
  - 泄漏：`expectArray` 原转移所有权但调用方只释放数组，元素泄漏；改为借用语义后消除。
  - 验证结果：`zig build test --summary all` → **27 项通过、退出码 0**；
    集成 9 项（握手/RESP3/批量/管道/前缀搜索/锁/结构体/PubSub/池并发）。

- **2026-11-18（首轮）· 工程纪律落地**
