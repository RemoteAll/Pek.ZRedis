### Zig 0.17 实测坑（已修，勿回退）
- 按值返回结构体不能存内部指针：`Reader` 要按值持有 `Stream`，`Client` 要按值快照 `ConnConfig`，
  否则 Windows AFD 句柄读报 `INVALID_HANDLE`。
- Windows Threaded：`netConnectIpWindows` 带 timeout 是 `@panic`；`operateTimeout` 返回 `ConcurrencyUnavailable`。
  读写超时改套接字 `SO_RCVTIMEO`/`SO_SNDTIMEO`（`client.setSocketTimeouts`）。
- `expectArray` 用**借用**语义；元素由 `Value.deinit` 释放（曾只 free 数组导致 bulk 泄漏）。
- `std.Io.Threaded.io()` 指向实例本身；测试里用堆上的 holder 保证生命周期。

### 真实实现对拍要点
- 锁：值 `{token}|{绝对过期毫秒}`、TTL `ceil(msExpire/1000)`、抢占用 `SET XX` 再校验、释放校验 token；
  时钟域用 `bootTicksMs()`（`GetTickCount64` / `CLOCK_MONOTONIC`）。
- 前缀：`EnsureStart`（不重复加、忽略大小写）；`search` 返回去前缀的键。

### 第二轮完成（队列 / 服务 / Tair）
- `src/queues/{base,status,queue,delay,reliable}.zig`：普通（LPUSH/RPOP/BRPOP）、延迟（`{key}:Delay` ZSet）、
  可靠（`{key}`/`:Ack:{消费者}`/`:Status:` 7 天/`:AllStatus` 抢清理/`:Error:{md5}` 备份库 30 天 10 次丢弃）。
- `src/services/{redlock,deferred,stat}.zig`：RedLock（普通 SET + quorum + 1% 漂移 + 比较令牌 Lua，释放按前缀拼键）、
  Deferred（SPOP 批处理 + 失败回写）、Stat（RENAME 快照 + HGETALL + i32 校验）。
- `FullRedis`：`getQueue/getDelayQueue/getReliableQueue/getDeferred/createSub/rename` + Tair `Ex*`。
- 参考实现口径（源码为证）：`EXHINCRBY` 返回**整数**（Rust `tair.rs` `as_i64()`），`EXINCRBY` 返回 `[值, 版本]`；
  RedLock 用普通 SET（Rust `services.rs` 注释明写「非 NX」）；`rollbackAck(from, to)` 第二参是**主队列键**。
- 实测修正：`ReliableQueue.init` 多余 dupe 消费者键（每次 8 B 泄漏）→ 直接格式化 `&consumer`；推迟转移整数显式 `i64`；
  假 Redis 补 `RPOPLPUSH`/`BRPOPLPUSH`、解锁 `EVAL`、Tair `EX*`。
