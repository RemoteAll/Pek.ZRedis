### 已完成能力
- 核心：`resp`（RESP2/3）、`options`、`client`（HELLO/AUTH/SELECT + 管道 + 阻塞）、`pool`、`encoder`、
  `redis`（基础命令）、`full`（前缀/SCAN/锁）、结构体（hash/list/set/zset/stack/geo/HLL）、`pubsub`。
- 队列：普通（LPUSH/RPOP/BRPOP）、延迟（`{key}:Delay` ZSet）、可靠
  （`{key}`/`:Ack:{消费者}`/`:Status:` 7 天/`:AllStatus` 抢清理/`:Error:{md5}` 备份库 30 天 10 次丢弃）。
- 服务：RedLock（普通 SET + quorum + 1% 漂移 + 比较令牌 Lua，释放按前缀拼键）、
  Deferred（SPOP 批处理 + 失败回写）、Stat（RENAME 快照 + HGETALL + i32 校验）。
- Stream：`__data` 基元 / 对象扁平化 / JSON 数组成对；消费组「抢回挂起 → `>` 新消息 → `0` 补读」；
  `retry_ack` 节流 60s + `XCLAIM` + 达 `max_retry` 丢弃 + 清理空闲 >1h 消费者；`from_last_offset` 首消费 `SETID $`。
- EventBus：`RedisEventBus(T)`，默认 `from_last_offset=true`、保留 3 天、维护 10 分钟。
- Tair：`EX*` 全家（`EXHINCRBY` 返回整数，`EXINCRBY` 返回 `[值, 版本]`）。

### 实测坑（勿回退）
- 按值返回结构体不能存内部指针：`Reader` 按值持有 `Stream`、`Client` 按值快照 `ConnConfig`（否则 `INVALID_HANDLE`）。
- Windows Threaded：`netConnectIpWindows` 带 timeout 是 `@panic`；`operateTimeout` 返回 `ConcurrencyUnavailable`；
  超时改套接字 `SO_RCVTIMEO`/`SO_SNDTIMEO`。
- `expectArray` 借用语义，元素由 `Value.deinit` 释放；`std.Io.Threaded.io()` 不能按值拷贝。
- `setGroup` 必须**先复制后释放**（传入自身 `group_name` 会自别名 → 重复建组、XPENDING 挂起恒 0）；`retryAck` 组名要局部 dupe。
- `std.json.parseFromSlice` 默认**借用输入**：临时缓冲必须 `.allocate = .alloc_always`（否则拿到 `UUUUU` 悬空串）。
- 不要手动释放 `std.json.Value` 内部（由 `Parsed.deinit()` 统一释放，手动 free 会 `free of invalid memory`）。
- `ReliableQueue.init` 不要额外 dupe 消费者键（曾每次 8 B 泄漏）。

### 真实实现对拍要点
- 锁：值 `{token}|{绝对过期毫秒}`、TTL `ceil(msExpire/1000)`、抢占用 `SET XX` 再校验、释放校验 token；时钟域 `bootTicksMs()`。
- 前缀：`EnsureStart`（不重复加、忽略大小写）；`search` 返回去前缀的键。
- 可靠队列 `rollbackAck(from, to)` 第二参是**主队列键**；RedLock 加锁用普通 SET（Rust 注释明写非 NX）。
